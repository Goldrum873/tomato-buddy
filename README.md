<h1 align="center">Tomato Buddy</h1>
<p align="center">A little tomato on your Stream Deck that watches over your Claude Code sessions.</p>

---

## What it does

- **One key per session** — see at a glance which session is working, which one is done, and which one is waiting for you.
- **One press opens the right terminal** — even with several conversations in the same VS Code window.
- **Smart ordering** — sessions waiting for you come first, then finished ones, oldest first.
- **Plan usage** — 5-hour and weekly usage gauges.
- **Sounds** — a soft chime when a session is done, a double ding when one needs you.

## Requirements

- Windows 10 / 11
- Stream Deck software 7.1 or later
- Claude Code running in a terminal (VS Code, Cursor or Windsurf recommended)

## Getting started

1. Install Tomato Buddy from the Elgato Marketplace — the *Tomato Buddy* profile is added automatically.
2. Press the tomato key showing **Install**. That's it.

## Privacy

Everything stays on your computer. Tomato Buddy only listens on `127.0.0.1` and never sends data anywhere.
It never reads or stores your Claude credentials: usage figures come from the official Claude Code status line.
